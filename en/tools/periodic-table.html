Periodic Table and element data

Browse the periodic table with different display options and access 40+ properties for each element: physicochemical properties, compounds, electron structure, historical data, and others such as sources of extraction and uses. Includes an element search by property value range, stable and radioactive isotope data, and trend charts — all offline.

What it includes

Chemical Suite's periodic table is not just an image: it includes different display options and a data card with 40+ properties for each of the 118 known elements.

Display options

Browse the full periodic table with different display options.

Physicochemical properties

Physical and chemical data for each element, part of the 40+ available properties.

Compounds

Look up compounds related to each element.

Electron structure

Visualization of each element's electron structure.

Historical data

Information about the history of each element.

Sources and uses

Data on where each element is obtained from and what it's used for.

Search by value range

Search for elements by filtering a range of values for any of their properties.

Stable and radioactive isotopes

300+ stable and radioactive isotopes of the elements.

Trend charts

Visually compare how element properties change across a group or period.

How it works in the app

  • Open the periodic table from Chemical Suite's main menu and choose your preferred display option.
  • Tap any element to open its full data card: physicochemical properties, compounds, electron structure, history, and sources and uses.
  • Use the value-range search to filter elements by any property.
  • Check stable and radioactive isotopes, and the trend charts to compare elements.
